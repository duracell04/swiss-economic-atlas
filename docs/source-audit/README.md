For each exact dataset, record download location and identifier, definition, unit and scale, frequency and period convention, actual coverage, revisions, historical breaks, and dataset-specific usage evidence. Assign distinct source IDs when terms or methodologies differ.

Review both the source record and its series definitions. Mark `verified` only when the evidence is complete. Set `redistribution: permitted` only with documented licence, conditions, attribution, evidence URL and review date. Unknown/restricted sources remain reference-only records without tracked observations.
